# Game Development Preferences

- Prefers expanding and deepening existing working code over replacing it with a new concept. Confidence: 0.6
- Prioritizes mechanical depth and presentation/juice over content volume and narrative in game design. Confidence: 0.6
- Prefers code-generated (asset-free) visuals and audio with moderate polish over external sprite/audio assets. Confidence: 0.6
- Leans toward keyboard-only controls (minimal input surface), declining gamepad support when offered. Confidence: 0.5
- Prefers minimal audio scope — SFX only, declining music/ambient beds when offered. Confidence: 0.5
- Prefers physics-based ball bounce where paddle velocity influences the exit angle, valuing skill-expressive, tactile feel over fixed-angle bounces. Confidence: 0.6
- Notices and wants corrected visual/rendering defects (e.g., square shapes where circles are expected, UI text clipping off-screen), valuing visual fidelity and clean UI layout. Confidence: 0.5
